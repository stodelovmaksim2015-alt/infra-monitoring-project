
# Infrastructure Monitoring Project

Проект для мониторинга доступности API, анализа логов и контейнеризации сервисов

# Технологии

Linux Ubuntu
Bash
Git и GitHub
Wireshark
Docker и Docker Compose
GitHub Actions
Nginx

# Возможности проекта

Проверка доступности API с помощью Bash
Анализ HTTP логов
Запуск API сервиса и прокси через Docker Compose
Автоматическое тестирование с GitHub Actions
